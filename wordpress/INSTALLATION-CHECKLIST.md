# HIT WordPress installation checklist

- [ ] Back up the WordPress database and files.
- [ ] Deactivate the earlier standalone HIT Enquiries plugin, if present.
- [ ] Install the HIT parent theme.
- [ ] Install and activate the HIT child theme.
- [ ] Install and activate HIT Core.
- [ ] Confirm 27 managed pages, six programs and three intakes.
- [ ] Confirm the homepage is assigned under Reading settings.
- [ ] Save Post name permalinks.
- [ ] Review both editable navigation menus.
- [ ] Set the Admissions email recipient.
- [ ] Configure authenticated SMTP or transactional email delivery.
- [ ] Send the enquiry test email.
- [ ] Submit one Study Cost Model enquiry and verify the record, applicant PDF and Admissions notification.
- [ ] Review privacy wording and retention with the responsible legal/operations team.
- [ ] Purge page cache and CDN after deployment.
